# Irmak · Español

Interactive practice for Irmak (B1–B2): KCL-style mock grammar tests, an indicative/subjunctive quiz and
fix-the-error sentences.

`index.html` is generated by `students/irmak/practica-subjuntivo/build.py` in the AgentWorkspace
languages folder (`irmak-practica.html`); edit `data.py` there, rebuild, and copy it here.
